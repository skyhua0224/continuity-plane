# Continuity Plane 0.1.0-alpha.22

本版本针对大型 C/C++ 平台仓库和多执行方主控会话优化检索与交接：C/C++/Objective-C
符号、配置键、多词 AND 查询、协作卡摘要筛选、执行记录字段、过期恢复提示、Todo/在途
卡合并提示、宿主 lifecycle bridge、检索字节计量和直接 `status --root` 均已加入。

This release improves retrieval and handoff for large C/C++ platform repositories and controller
sessions: native lexical symbols, configuration keys, AND queries, bounded task summaries and
filters, executor evidence fields, stale recovery warnings, Todo/in-flight projection, a host
lifecycle bridge, retrieval byte metrics, and direct `status --root` rendering.

Usage based provider handoff remains a design item. It is not enabled by this release.
