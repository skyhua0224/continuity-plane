# Use cases

[中文](use-cases.md) · [Workflows](workflows.en.md) · [Validation](validation.en.md)

These are current entry points and limits, not claims that every problem is fully solved. Historical numbers stay with their [original methods](benchmarks.en.md).

## Compaction makes the agent look different

Enabled host hooks save bounded return points and a shared plan, batch, workers and pending decisions. Without hooks, read handoff/packet explicitly. No tool preserves every conversational detail or guarantees upstream automatic compaction.

## Sessions step on each other

Explicit controller leases, atomic reservations and controller run coordinate tool-mediated operations. They are not OS isolation or protection for arbitrary Git. Choose an authority host and upgrade participants rather than sharing live SQLite across machines.

## People and agents repeat each other's work

Cards, changes, reports and batches provide common records; wait blocks for events. Recipients retrieve and acknowledge inbox messages; wake-up is not guaranteed. Reconnect ownership usability still needs work: a connection ID is not a permanent executor identity.

## A casual idea pulls the mainline away

Commitments, lessons and next_action retain small unfinished matters. Full typed Idea/Work switching is an advanced State path. Discussion does not automatically create work or authorization.

## Large projects lose their shape

Bounded lookup locates symbols; indexed include/link relations and prompt code routes reduce discovery. This is not a complete compiler call graph or universal multilingual impact analysis. Projections/full UI have separate coverage. Follow misses with narrow source investigation.

## Memory, skills and documents drift

Rules carry hashes/attachments; source records retain versions, sections and adoption reasons; lessons keep corrections. Drift checks cover implemented references/cards. Dedicated source TSV round trips are still missing; do not require a second manually maintained ledger. Recording or reminding is not actual adoption.
