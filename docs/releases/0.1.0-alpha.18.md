# Continuity Plane 0.1.0-alpha.18

This release exposes the ordered intent TodoQueue through MCP.

## Changes

- Added `continuity_todo_compile` for multi-item user requests.
- Added `continuity_todo_list`, `continuity_todo_complete`, and `continuity_todo_block`.
- TodoQueue writes remain local sidecar metadata and never grant State or external-effect authority.
- The existing Stop hook continues ordinary work while the queue remains active.

## Install

```bash
python -m pip install --upgrade continuity-plane==0.1.0a18
codex plugin marketplace add skyhua0224/continuity-plane
codex plugin add continuity-plane@continuity-plane
```

Start a new Session after installing the plugin so the MCP TodoQueue tools are visible.
