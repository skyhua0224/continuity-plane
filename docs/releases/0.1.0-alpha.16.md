# Continuity Plane 0.1.0-alpha.16

This release adds guarded automatic continuation at the Codex Stop lifecycle boundary.

## Changes

- The core plugin registers a synchronous `Stop` hook.
- A continuation is requested only after explicit execution intent and a fresh, writable active
  Work with a resumable `next_action`.
- Stale/read-only State, open blockers, missing packets, and Stop re-entry stay silent; ordinary
  work is never blocked by the hook.
- Added lifecycle coverage for continuation and loop prevention.

## Verification

- Lifecycle, advisory, plugin-profile, and public-release tests pass.
- Public mirror scan and package build are expected to run as part of release publication.

## Install

```bash
python -m pip install --upgrade continuity-plane==0.1.0a16
codex plugin marketplace add skyhua0224/continuity-plane
codex plugin add continuity-plane@continuity-plane
```

Start a new Session after installing the plugin so the Stop hook is loaded.
