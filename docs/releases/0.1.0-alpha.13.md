# Continuity Plane 0.1.0-alpha.13

## 中文

这一版把默认路径收回“零阻力连续性”：Continuity 继续提供恢复点、有界检索和观测，但不再因为 State、lease 或检索短暂不可用而阻断普通开发。

### 主要更新

- Codex 生命周期改为清晰的非阻断分工：PreCompact 负责 checkpoint，PostCompact 只做 canary 校验，压缩后的 SessionStart 是唯一恢复上下文注入点，避免重复指令和重复消耗。
- Interaction Cursor 识别明确的继续、执行、完成和验收指令；信息型问题才按问答处理，避免把“做完再报告”误判成只允许回答。
- advisory PreToolUse/PostToolUse 提供一次性有界读取、live shell handle 轮询和长命令后续推进提示；不调用 State、不改写命令、不拒绝普通操作。
- doctor 解析 marketplace 实际插件运行时，校验 6/6 hook 命令、脚本入口、no-op stub、包版本漂移、active claim 80% 租约预警和 resume packet 体积；陈旧 cache 不再被误报为 ready。
- 显式安装器支持 cc-switch 已完全卸载的机器，并把 OpenCodex 管理的 Codex config/catalog 与 systemd/basic-auth 稳定配置纳入进程内 HMAC 指纹；任何并发漂移都会中止安装。
- 迁移提示：旧版本写入的 remain-read-only 状态需要一次受控 reclaim 事件才会恢复；新版本不再产生该默认停等状态。
- strict effect policy 只用于 CI 或明确要求强制拦截的场景；日常开发默认为非阻断 auto。

### 实测与边界

- 内部全量测试 2143/2143 通过，31 项按环境跳过。
- 公开 fresh-history mirror 149 个文件；公开测试 52/52、ruff、compileall、wheel 干净安装 smoke 全部通过。
- gitleaks 8.30.1 扫描公开树 4.45MB，未发现泄漏；公开 banned marker 和历史扫描为 0。
- hook 效率基准：Continuity 调用减少 33.33%，模型上下文减少 33.55%，deny/stop 均为 0。
- 文档生命周期基准：STATUS 缩减 83.27%，live validator p95 39.24ms。
- 这些是本次发行边界的实测，不等于对所有项目、模型和窗口的普遍 token 节省承诺；matched A/B 仍继续执行。

## English

This release returns the default path to zero-friction continuity: Continuity supplies return points, bounded lookup, and observation without blocking ordinary development when State, leases, or lookup are temporarily unavailable.

### What changed

- The Codex lifecycle now has a clear non-blocking division: PreCompact creates the checkpoint, PostCompact verifies the canary, and compact SessionStart is the only recovery-context injection point. Duplicate instructions and duplicate consumption are gone.
- The interaction cursor recognizes explicit continue, execute, finish, and acceptance requests. Only information requests are answered in place, so “finish it before reporting” no longer degrades into answer-only mode.
- Advisory PreToolUse/PostToolUse hooks add one-shot bounded-read, live shell-handle polling, and long-command continuation guidance. They do not call State, rewrite commands, or deny ordinary operations.
- Doctor resolves the marketplace-selected plugin and validates all six hook commands, script entrypoints, no-op stubs, package-version drift, the 80% active-lease warning, and resume-packet size. A stale cache can no longer be reported as ready.
- The explicit installer supports machines where cc-switch is completely uninstalled and fingerprints OpenCodex-managed Codex config/catalog plus stable systemd/basic-auth surfaces with process-keyed HMACs. Concurrent drift aborts the install.
- Migration note: a remain-read-only state written by an old version requires one controlled reclaim event; the new version no longer produces that default wait state.
- The strict effect policy is for CI or workflows that explicitly require mandatory blocking. Daily development remains non-blocking auto by default.

### Verification and boundaries

- Internal full suite: 2143/2143 passed, with 31 environment skips.
- Public fresh-history mirror: 149 files; public tests 52/52, ruff, compileall, and a clean wheel-install smoke all passed.
- gitleaks 8.30.1 scanned 4.45MB of the public tree with no leaks; public banned-marker and history scans returned zero.
- Hook efficiency benchmark: Continuity calls fell 33.33%, model context fell 33.55%, and deny/stop counts were both zero.
- Document lifecycle benchmark: STATUS shrank 83.27%, with a 39.24ms live-validator p95.
- These measurements apply to this release boundary and are not a universal token-savings claim across every project, model, and context window; matched A/B work continues.
