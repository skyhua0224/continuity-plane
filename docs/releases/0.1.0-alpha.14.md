# Continuity Plane 0.1.0-alpha.14

Alpha14 adds the first generic collaboration and semantic-memory layer while preserving
non-blocking local development.

## New

- Project registration for multi-repository and worktree-aware identity.
- Bounded task cards with temporary assignees and ready-for-review.
- Read-only external-effect request queue for push, PR, merge, deployment, and package publication.
- Global/project vocabulary memory with secret rejection and project override rules.
- One-shot Codex prompt injection for the current task and matched vocabulary.
- collaboration packet CLI and continuity_collaboration_packet MCP tool.
- Report-only skills and Git worktree inventories.
- Collaboration health in continuity doctor.

## Safety boundary

Collaboration metadata is advisory. It never grants State completion authority or external-effect
authority, and a missing or damaged sidecar never disables ordinary local reads, edits, builds, or
tests.

## Verification

- Generic collaboration, memory, inventory, and hook tests pass.
- Codex MCP binding/advisory tests pass.
- Public release mirror/profile tests pass.
- Ruff passes on the changed Python modules.

The alpha14 candidate can be built from this source tree. Public package and
marketplace publication remain a separate release action.
