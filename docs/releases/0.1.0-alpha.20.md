# Continuity Plane 0.1.0-alpha.20

This release reduces report noise and adds concise technical-language rendering guidance.

## Changes

- Long successful commands are silent by default; Stop and TodoQueue boundaries remain the continuation points.
- Added concise technical Chinese guidance based on ASD-STE100 principles.
- The guidance is applied at report boundaries and does not load as a permanent skill or gate ordinary work.
- Includes the MASTER-bound TodoQueue and MCP tools from the previous release line.

## Install

```bash
python -m pip install --upgrade continuity-plane==0.1.0a20
codex plugin marketplace add skyhua0224/continuity-plane
codex plugin add continuity-plane@continuity-plane
```
