# Continuity Plane 0.1.0-alpha.19

This release makes MASTER the plan authority while keeping State ownership and effects separate.

## Changes

- TodoQueue records the MASTER path and hash used to compile it.
- A changed MASTER causes a bounded reconciliation hint instead of replaying stale Work order.
- Added `continuity plan inspect` for hash-bound, read-only plan routing.
- Existing State, claim, checkpoint, and external-effect rules remain unchanged.

## Install

```bash
python -m pip install --upgrade continuity-plane==0.1.0a19
codex plugin marketplace add skyhua0224/continuity-plane
codex plugin add continuity-plane@continuity-plane
```
