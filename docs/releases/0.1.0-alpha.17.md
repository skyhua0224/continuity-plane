# Continuity Plane 0.1.0-alpha.17

This release adds ordered intent TodoQueues for multi-item user requests.

## Changes

- Numbered and bullet multi-item requests are compiled into a bounded local queue.
- The queue persists outside SQLite and exposes `continuity todo list|complete|block`.
- The current item and its exact completion command are injected into the Session context.
- Stop continuation advances ordinary work while items remain, while blockers and user decisions pause safely.
- Read-only Continuity State does not prevent ordinary source edits or tests.

## Install

```bash
python -m pip install --upgrade continuity-plane==0.1.0a17
codex plugin marketplace add skyhua0224/continuity-plane
codex plugin add continuity-plane@continuity-plane
```

Start a new Session after installing the plugin so the TodoQueue and Stop hook are loaded.
