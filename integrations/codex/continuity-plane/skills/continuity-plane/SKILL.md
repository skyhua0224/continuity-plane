# Superseded Skill Path

The default core plugin no longer registers a state workflow Skill. The current
workflow contract is provided by the optional `continuity-plane-state` plugin.
Large-repository lookup guidance is provided by the optional
`continuity-plane-search` plugin.

This tombstone preserves document lineage and grants no State, memory,
completion, command, or external-effect authority.
